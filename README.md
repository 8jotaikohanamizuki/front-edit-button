1. 未ログイン状態の場合
条件: WordPressにログインしていないユーザー
表示されるボタン: 「ログイン」ボタン
動作: 押すとWordPressのログイン画面（またはGoogleソーシャルログイン）へ遷移。ログイン完了後は、元々閲覧していたページへ自動的にリダイレクト（戻る）される仕組み。
目的: 一般閲覧者やログイン前のメンバーにログインを促す。
2. ログイン済み ＋ 編集権限あり（エディターや投稿者など）
条件: ログインしており、かつ該当の記事を編集できる権限を持っているユーザー
表示されるボタン: 「この記事を編集する」ボタン
動作: 押すと該当記事のWordPress管理画面（編集ページ）へ直接遷移する。
3. ログイン済み ＋ 編集権限なし（閲覧専用メンバーなど）
条件: ログインしているが、記事の編集権限を持たないユーザー
表示: 何も表示しない（空欄）
目的: クラウドフレア等で事前に登録済みの閲覧専用ユーザーに対しては、余計なボタンを見せずスムーズに記事を閲覧させる。
